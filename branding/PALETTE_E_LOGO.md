# PuntoFedele – identità grafica

**Nome dell'app:** PuntoFedele (programma di raccolta punti per un negozio)

**Logo:** una tessera fedeltà bianca, leggermente inclinata, con una stella color accento, su sfondo verde petrolio.

## Palette

| Ruolo | Colore | Uso |
|-------|--------|-----|
| Principale | `#0F766E` | Pulsanti, titoli, voce di menu selezionata, intestazioni |
| Principale scuro | `#134E4A` | Testo del nome, sfondi scuri |
| Accento | `#F59E0B` | Stella del logo, evidenziazioni |
| Principale chiaro | `#CCFBF1` | Banda della tessera, sfondi leggeri |
| Punti positivi | `#2E7D32` | Acquisti e punti accreditati |
| Punti negativi | `#C62828` | Riscatti, annullamenti e punti scalati |

Nel codice i colori sono definiti in `flutter/lib/theme.dart`.

## File

| File | Uso |
|------|-----|
| `logo_icona.svg` / `.png` | logo quadrato (login, menu, icona dell'app) |
| `logo_orizzontale.svg` / `.png` | logo con il nome, per documenti e presentazioni |
| `palette.png` | riepilogo dei colori |
| `web_icons/` | icone del sito (favicon e icone dell'app) |
